🛒 React Shopping Application

A fully functional e-commerce product listing and shopping cart application built with React, Redux Toolkit, and React Bootstrap. This project features full CRUD operations, a persistent shopping cart using localStorage, and a custom API.

✨ Features

    Product Management (CRUD): View, add, edit, and delete products.

    Shopping Cart: Add products to the cart with duplicate prevention.

    State Management: Utilizes Redux Toolkit for global cart state management.

    Data Persistence: Cart data is saved to the browser's localStorage, meaning the cart won't empty on a page refresh.

    Custom Fetch Hook: Uses a custom useFetch hook for clean API requests.

    Interactive UI: Built with React Bootstrap for responsive cards and buttons.

    Smooth Alerts: Integrated with SweetAlert2 for beautiful confirmation and success messages (e.g., when deleting a product).

    Loading States: Includes a custom loading indicator (react-loading-indicators) while fetching data.
